ASS subtitles, drawn by the browser.

PAR renders .ass / .ssa in plain DOM, SVG and CSS. No WebAssembly, no framework, about 22 kB gzipped.

What you get

Docs

Install

npm install pulsar-ass-renderer
<script src="https://unpkg.com/pulsar-ass-renderer/dist/par.global.js"></script>

Use

import { create } from 'pulsar-ass-renderer';
const par = create({
  video: document.querySelector('video'),
  subtitle: assText,
});
